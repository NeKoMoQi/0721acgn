# 类别配图（原帖没有配图时用）

`config.json` 的 `category_covers` 决定每类文章用哪张图，优先级是：

1. 原帖/原视频自带的封面（`cover_mode: source`）
2. 本目录里对应的类别图
3. `default.png`
4. 都没有才回退到程序插画

## 放文件就行

把你的图片按下面名字丢进这个目录，脚本会自动用（建议 16:9，1280×720 以上，PNG/JPG 都行，但配置里写的是 `.png`，换格式记得同步改 `config.json`）：

| 文件名 | 用在 |
| --- | --- |
| `anime.png` | 番剧、新番、剧场版、PV |
| `comic.png` | 漫画、条漫、连载 |
| `novel.png` | 轻小说、文库、新刊 |
| `game.png` | 游戏、手游、赛季、版本、实机 |
| `esports.png` | 赛事、联赛、战队、夺冠、选手 |
| `default.png` | 以上都不是时的兜底（已放了一张站内背景图） |

分类是按标题和摘要里的关键词猜的（见 `media.py` 的 `CATEGORY_RULES`），同一篇文章可能跨类，顺序是：赛事 → 番剧 → 漫画 → 小说 → 游戏。

## 注意

- 这些图会印在资讯卡片和详情页顶部，建议用自有素材或有明确授权的图，别直接搬别人的作品。
- 缺哪个文件就会自动用 `default.png`，不会报错。
- 换图不需要重启服务，但**已经发布的老文章不会自动换**——封面是发布时写死的 PNG；要换得重新生成或手工替换 `data/media/<稿件ID>-cover.png`。
