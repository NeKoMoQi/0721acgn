# 验证记录（v2，2026-10-23）

## 实际网络采集

- 安装并运行 bilibili-api-python 17.4.2 的只读采集器。最小诊断配置（一个关键词、一个动画榜、每列表 3 条）实际得到 9 条 B站视频，无列表错误；取得真实播放、评论和点赞统计。
- 同次对一条视频实际读取到 3 条热门评论。未登录时字幕返回 CredentialNoSessdataException，只有 1 字视频简介，不能用来写正文。本机不存在 DSH B站登录凭证。
- 小黑盒在独立无账号 Chromium 会话中实际取得 10 条信息流帖子，能读取标题、日期、评论数。浏览和点赞数未取得，保留 null。
- 深入打开帖子时返回的内容最初只是信息流摘要；检查后已修正：只有 text/content 或页面文章正文才认作全文。当前匿名会话读取全文失败，会明确返回 CollectionError/登录指引，不再把摘要当全文。小黑盒登录后全文及评论读取尚待用户完成登录后验证。
- 原始 Python urllib 直接访问 B站热门接口曾收到 HTTP 412；随后上述接口库的实际列表读取成功。结果只证明本机当次访问，不能保证目标服务器或后续时段同样可用。
- 真实平台诊断不调用 DeepSeek，没有模型费用。本机无 DEEPSEEK_API_KEY，因此真实付费写稿和实际网站自动发布尚未执行。

## 打包边界

v2 包为源码部署包：包含 newsroom 服务、依赖清单、登录/诊断命令、计划任务和 systemd，以及网站涉及的当前源码快照。无 API Key、Cookie、浏览器用户目录、数据库、真实稿件、node_modules、dist 或 jar。

部分网站文件包含本次之前已有的本地修改。合入服务器其他版本前先对比备份，不要盲目覆盖整份源码，更不要覆盖服务器配置和 data。旧版 SQLite 自动迁移；旧 config.json 中的 auto_publish=false 保持原值，需按文档改为 true 才启用自动发布。
