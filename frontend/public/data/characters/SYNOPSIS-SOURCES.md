# 角色简介来源

`synopsis-*.json` 中的正文取自 [Bangumi 番组计划 2026-11-24 Wiki 归档](https://github.com/bangumi/Archive/releases/download/archive/dump-2026-11-24.210413Z.zip)，由各角色条目的贡献者编写，依据 [Bangumi 版权声明](https://bgm.tv/about/copyright) 以 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 提供。

每组正文以 Bangumi 角色 ID 为键。对应原条目为 `https://bgm.tv/character/{id}`。本站调整了段落、排版和标记，并筛除有外部出处标记的简介。站内原创简介和图片各自保留原有的来源标注。

同一份归档也提供人物关系。关系标签依据 [Bangumi 的公开定义](https://github.com/bangumi/common/blob/master/person_relations.yml) 显示，带剧透标记的关系未纳入。
