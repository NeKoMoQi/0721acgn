先明确作品或城市范围、可用天数、主要交通方式和体力偏好。没有城市也可以从作品的站内取景点分布开始，但不能在范围不明时随机拼路线。

每天通常选 3～5 个主要地点，休闲安排可以更少；不要为了点数把相距很远的地点塞进同一天。参考坐标把相近地点放在一起，减少折返，午间留出休息空间。

按天数分别说明主题、地点顺序与选择理由。多日行程保留天数边界；修改某一天时，保留主人明确要求不变的其他天，并提交完整新版本。

经纬度只能做距离粗筛，不能证明道路连通、实际步行里程或交通耗时。若相距过远，应减少地点、拆天或询问是否接受其他交通方式；不要默默改为驾车。

知识库的方法建议不能代替具体地点查询。资料少时选择更短而可靠的行程，并说明缺口。
